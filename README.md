# ریشه | Rishe

اپ آموزش زبان انگلیسی با پنل مدیریت PHP.

این پروژه دو بخش دارد:

| پوشه | چیست |
|---|---|
| `server/` | پنل مدیریت و API اپ، با PHP خالص و MySQL و بدون هیچ وابستگی |
| `app/` | اپ اندروید با Capacitor (رابط HTML/CSS/JS) |

فایل APK در هر بار push به شاخه‌ی `main` به‌صورت خودکار ساخته می‌شود و در بخش **Releases** همین ریپازیتوری قرار می‌گیرد.

---

## امکانات نسخه‌ی ۱

**اپ:**
- ورود و عضویت با موبایل و رمز. اگر پیامک فعال باشد، ورود با کد یک‌بارمصرف و بازیابی رمز هم فعال می‌شود.
- دوره ← فصل ← مرحله. مرحله‌ها به ترتیب باز می‌شوند.
- هر مرحله شامل این‌هاست:
  - جمله‌ی انگلیسی که با زدن روی هر واژه، معنی آن نمایش داده می‌شود
  - پخش صدا با سرعت عادی یا آهسته
  - تلفظ به دو شکل: آوانگاری (IPA) و فارسی‌نویسی
  - معنی فارسی
  - توضیح صوتی مدرس
- تمرین آخر هر مرحله: انتخاب معنی یا سؤال شنیداری، با بازخورد درست و غلط
- امتیاز، شمار روزهای پیاپی تمرین و تعداد عبارت‌های آموخته
- آزمون پایانی دوره که پاسخ‌هایش روی سرور تصحیح می‌شود
- درخواست مدرک ← تأیید در پنل ← مشاهده‌ی مدرک در اپ، به‌همراه لینک استعلام عمومی
- حالت تیره

**پنل مدیریت:**
- داشبورد آمار
- مدیریت دوره، فصل، مرحله، عبارت (با آپلود صدا) و سؤال
- آزمون پایانی هر دوره
- کاربران: جستجو، مسدودسازی و دادن اشتراک دستی
- مدارک: تأیید، رد یا ابطال، با دلیل
- طرح‌های اشتراک و گزارش پرداخت‌ها
- تنظیمات: برند، امضای مدرک، پیشوند کد مدرک، هزینه‌ی صدور مدرک، **کلید مرچنت زیبال**، پیامک کاوه‌نگار

**درآمد (فعلاً خاموش):** دکمه‌ی «فعال‌سازی پرداخت» در تنظیمات است. تا وقتی خاموش باشد، همه‌ی دوره‌ها رایگان‌اند. وقتی روشن شود:
- دوره‌هایی که «ویژه» علامت خورده‌اند فقط با اشتراک یا خرید تکی باز می‌شوند. مرحله‌هایی که «پیش‌نمایش رایگان» دارند همچنان باز می‌مانند.
- اگر برای صدور مدرک هزینه تعیین شده باشد، از کاربر گرفته می‌شود.
- پرداخت از درگاه زیبال انجام می‌شود.

## نصب سرور

۱. محتوای پوشه‌ی `server/` را روی هاست آپلود کنید، مثلاً در `public_html/rishe`.
۲. یک دیتابیس MySQL بسازید.
۳. آدرس `https://your-site.ir/rishe/install.php` را باز کنید و اطلاعات دیتابیس و مدیر را وارد کنید. گزینه‌ی «دوره‌ی نمونه» یک دوره‌ی آماده برای تست می‌سازد.
۴. بعد از نصب، **فایل `install.php` را حذف کنید.**
۵. وارد پنل شوید: `https://your-site.ir/rishe/admin/`

نیازمندی‌ها:
- PHP 8.0 یا بالاتر، با افزونه‌های `pdo_mysql`، `curl`، `fileinfo` و `mbstring`
- MySQL 5.7+ یا MariaDB 10.3+
- Apache با `mod_rewrite`

آدرس API برای اپ: `https://your-site.ir/rishe/api/v1/`

> اگر هاست شما Apache نیست (مثلاً Nginx)، همه‌ی درخواست‌های `/api/` را به `api/index.php` بفرستید. دسترسی به پوشه‌های `core/` و `database/` و فایل `config.php` را هم ببندید.

> **حتماً از https استفاده کنید.** اپ اندروید به آدرس http وصل نمی‌شود.

### درگاه زیبال
۱. در پنل زیبال درگاه بسازید و کلید مرچنت را بگیرید.
۲. در «تنظیمات» پنل، کلید را وارد کنید و «فعال‌سازی پرداخت» را بزنید. برای تست، مقدار `zibal` درگاه آزمایشی است.
۳. آدرس بازگشت به‌صورت خودکار `.../pay/callback.php` است.

### پیامک (اختیاری)
در کاوه‌نگار یک الگوی تأیید با متغیر `%token` بسازید. بعد API Key و نام الگو را در تنظیمات وارد کنید.

## ساخت APK

### خودکار با GitHub Actions
۱. در ریپازیتوری به **Settings → Secrets and variables → Actions → Variables** بروید و متغیر `RISHE_API_URL` را با آدرس API بسازید. مثال:
   `https://your-site.ir/rishe/api/v1/`
۲. هر push به `main` که پوشه‌ی `app/` را تغییر دهد، APK را می‌سازد. از تب Actions هم می‌شود دستی اجرا کرد (Run workflow).
۳. فایل `rishe-x.y.z-debug.apk` در **Releases** قرار می‌گیرد و برای نصب و تست مستقیم روی گوشی مناسب است.

**نسخه‌ی امضاشده برای کافه‌بازار و مایکت (اختیاری):** این چهار Secret را بسازید تا نسخه‌ی release امضاشده هم ساخته شود:
`RISHE_KEYSTORE_BASE64` (فایل keystore به base64)، `RISHE_KEYSTORE_PASSWORD`، `RISHE_KEY_ALIAS` و `RISHE_KEY_PASSWORD`.

ساخت keystore:
```bash
keytool -genkey -v -keystore rishe.keystore -alias rishe -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 rishe.keystore   # خروجی را در RISHE_KEYSTORE_BASE64 بگذارید
```
فایل keystore و رمزهایش را جای امنی نگه دارید. بدون آن‌ها نمی‌توانید نسخه‌ی بعدی را در بازار منتشر کنید.

### دستی روی کامپیوتر خودتان
نیازمندی‌ها: Node 18+، JDK 17 و Android SDK (یا Android Studio).
```bash
cd app
npm ci
# آدرس API را در www/js/config.js بنویسید
npx cap sync android
cd android && ./gradlew assembleDebug
# خروجی: app/android/app/build/outputs/apk/debug/app-debug.apk
```

## ساختار و استانداردها

- پیشوند همه‌چیز `rishe`:
  - توابع PHP: `rishe_`
  - کلاس‌ها: `Rishe_`
  - جدول‌ها: `rishe_`
  - کلاس‌های CSS: `.rishe-`
  - شیءهای JS: `Rishe*`
- همه‌ی کوئری‌ها با prepared statement اجرا می‌شوند و همه‌ی خروجی‌ها escape می‌شوند.
- همه‌ی فرم‌های پنل CSRF token دارند.
- رمزها با `password_hash` ذخیره می‌شوند و توکن‌های API به‌صورت هش در دیتابیس نگه داشته می‌شوند.
- ورود، ارسال کد پیامکی، آزمون و پرداخت محدودیت تعداد درخواست دارند.
- آپلود فقط فایل صوتی می‌پذیرد: پسوند و نوع واقعی فایل بررسی می‌شود، نام فایل تصادفی است و اجرای اسکریپت در پوشه‌ی `uploads` بسته است.
- شناسه‌ی اپ اندروید `ir.kasbomal.rishe` است. قبل از اولین انتشار در بازار، اگر لازم است تغییرش دهید (در `app/capacitor.config.json` و `app/android/app/build.gradle`). بعد از انتشار قابل تغییر نیست.

```
server/
  admin/        پنل مدیریت (admin/?p=...)
  api/          API اپ (api/v1/...)
  pay/          بازگشت از درگاه
  verify/       صفحه‌ی عمومی استعلام مدرک
  core/         کلاس‌ها و صفحه‌های پنل (دسترسی مستقیم بسته)
  database/     schema.sql و دوره‌ی نمونه
  assets/       CSS، JS و فونت پنل
  uploads/      فایل‌های صوتی آپلودشده
app/
  www/          رابط اپ (HTML/CSS/JS)
  android/      پروژه‌ی اندروید Capacitor
```

فونت وزیرمتن (Vazirmatn، با مجوز OFL) داخل پروژه قرار دارد، پس اپ و پنل به Google Fonts وابسته نیستند.
